# HTTP Multi-threaded web crawler 

## Overview
A Python-based HTTP web crawler that starts from a seed URL , downloads web pages , extracts , hyperlinks and crawls web pages within the same domain

## Features
-Crawl web pages using HTTP GET requests 
-Extract hyperlinks from HTML
-Avoid visiting duplicate URLs
-Multi-threaded crawling
-Logging 
-Unit testing with pytest

## Tech Stack
-Python
-Request
-BeautifulSoup4
-lxlm
-pytest
